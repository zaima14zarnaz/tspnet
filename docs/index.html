TSPNet: Object-Grounded Text Priors
for Saliency Ranking Detection

WACV 2027

Paper Supplement Code arXiv

Turning object-referential language into spatial guidance for saliency ranking.

Abstract

Saliency ranking detection (SRD) identifies multiple salient objects and orders them by relative visual importance. Existing methods mainly infer this hierarchy from visual appearance and inter-object reasoning, while recent language-guided approaches use descriptions largely as global scene context or caption-derived relations. We argue that language can more effectively complement visual evidence for SRD when object-referential sentences guide saliency ranking at the object level.

We propose TSPNet, a framework that converts detailed image descriptions into object-level auxiliary priors for saliency ranking. Without direct sentence–object saliency annotations, TSPNet learns text-conditioned auxiliary scores for CLIP-matched ROI–sentence pairs using human-annotated saliency ranks as indirect ordinal supervision. It renders these scores as spatial heatmap priors, while the corresponding text representations guide ROI feature refinement. This extends language guidance beyond global caption modulation toward ROI-specific saliency reasoning. Experiments on ASSR, IRSR, and SIFR show consistent improvements over strong recent baselines in the primary ranking metrics, SA-SOR and SOR. Ablations further show that these gains depend on meaningful linguistic cues and correct ROI–sentence correspondence.

Introduction

From a description of the scene to guidance for each object.

A description can tell us more than which objects are present. Attributes, interactions, and descriptive detail can provide useful cues about their visual importance.

Using an entire paragraph as global context can dilute object-specific cues. TSPNet instead matches each candidate region to an object-referential sentence and learns how this paired evidence relates to human saliency rankings.

The resulting scores become spatial priors, while the matched text also refines the corresponding ROI features. Visual evidence and scene context remain part of the final ranking decision.

Method

Object grounding, text-conditioned spatial priors, and text-adaptive visual features.

  1. Match sentences to objects. A separately trained segmentation branch predicts candidate masks. Frozen CLIP encoders match each ROI to the most similar sentence; low-similarity matches use empty text.
  2. Learn spatial priors. The Text-Conditioned Saliency Estimate (TCSE) module scores ROI–sentence pairs using pairwise ordinal supervision from human saliency ranks. A gated heatmap overlay injects these scores into the visual input.
  3. Refine and rank. The Multi-Kernel Text-Adaptive (MKTA) module uses matched text to condition convolutional filters over ROI features. Scene-context reasoning then supports final object-level saliency ranking.

Does Object–Text Grounding Matter?

A controlled matching-corruption experiment tests the importance of correct correspondence.

After CLIP matching, increasingly many matched sentences are reassigned to incorrect ROIs. Performance decreases as correspondence is corrupted, supporting the importance of matching linguistic evidence to the right object.
